Welcome to WinAFL Pet

Manage fuzzing jobs across your Windows machines, monitor progress, and collect crashes for analysis.

Start your first job

  1. Preparation

    Prepare your machine

    Set up WinAFL and confirm your target runs successfully from the command line. Prepare a few valid sample inputs, then install and start the WinAFL Pet agent.

  2. Setup

    Connect an agent

    Open Agents and register your fuzzing machine using the secret key generated during installation.

  3. Setup

    Create a job

    Open Jobs, select your agent, and configure tool locations, input/output directories, and target settings. Paths refer to the remote fuzzing machine.

  4. Start

    Start and monitor

    Click Start on the Jobs page and allow the initial dry run to finish. Use View to inspect fuzzing statistics and Stop when needed.

  5. Review

    Review crashes

    Click Collect on the job, then open Crashes and use Verify to analyze findings with BugId.

Before you connect

  • WinAFL and instrumentation installed on the fuzzing machine
  • Target or harness runs from the command line
  • Valid sample inputs
  • WinAFL Pet agent installed and started, with the generated key at hand
