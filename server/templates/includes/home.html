Welcome to WinAFL Pet

Run WinAFL across your Windows machines

Manage fuzzing jobs across your Windows machines, monitor progress, and collect crashes for analysis.

Start your first job

  1. 1

    Step 1: Prepare your machine

    Set up WinAFL and confirm your target runs successfully from the command line. Prepare a few valid sample inputs, then install and start the WinAFL Pet agent.

  2. 2

    Step 2: Connect an agent

    Register your fuzzing machine using the secret key generated during agent installation.

    New agent
  3. 3

    Step 3: Create a job

    Select your agent and configure tool locations, input/output directories and target settings. Paths refer to the remote fuzzing machine.

    New job
  4. 4

    Step 4: Start and monitor

    Click Start on the Jobs page and allow the initial dry run to finish. Use View run to inspect fuzzing statistics and Stop when needed.

    Open Jobs
  5. 5

    Step 5: Review crashes

    Click Collect crashes on the job, then open Crashes and use Verify to analyze findings with BugId.

    Open Crashes

Before you connect

  • WinAFL and DynamoRIO (or TinyInst) installed on the fuzzing machine
  • Target or harness runs successfully from the command line
  • A few valid sample inputs prepared
  • WinAFL Pet agent installed and started; secret key at hand
